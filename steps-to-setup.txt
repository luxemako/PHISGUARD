PHISHGUARD QUICK SETUP

Run these commands from the project root using Git Bash.

1. Create and activate the Python environment

py -3.11 -m venv backend/venv
source backend/venv/Scripts/activate
python -m pip install -r backend/requirements.txt

2. Configure PostgreSQL

Copy backend/.env.example to backend/.env
Replace YOUR_PASSWORD in backend/.env

CREATE DATABASE phishguard;

CREATE TABLE scans (
    id BIGSERIAL PRIMARY KEY,
    scan_type VARCHAR(20) NOT NULL,
    input_preview TEXT,
    prediction VARCHAR(20) NOT NULL,
    risk_score NUMERIC(5,2) NOT NULL,
    risk_level VARCHAR(20),
    warning_signs JSONB NOT NULL DEFAULT '[]',
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

3. Install frontend packages

cd frontend
npm install
cd ..

4. Put these datasets in datasets/raw/

450k URL.csv
phishing_email.csv

5. Prepare datasets

python backend/training/prepare_url_dataset.py
python backend/training/prepare_text_dataset.py

6. Train models

python backend/training/train_url_modal.py
python backend/training/train_text_model.py

7. Run backend

cd backend
python -m uvicorn app.main:app --reload

8. Run frontend in a second terminal

cd frontend
npm run dev

Open http://localhost:5173
